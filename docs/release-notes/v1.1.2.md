## 豆档 v1.1.2

这一版把「冲煮」从一张记录表变成了能对照数据的冲煮台：接上 TIMEMORE 电子秤，重量和流速实时画出来；没有秤也能按粉水比把方案算清楚。iPhone 上没有网页蓝牙，所以加了一条「一台设备当秤桥」的路线。

### 冲煮数据

- 新增「冲煮数据」面板：左右双轴折线，蓝线是注水量（g），绿线是注水流速（g/s），图例可单独开关，支持放大。
- 四个读数卡：时间、粉重（实际倒粉）、注水量（扣掉粉重后的净注入）、粉水比（按实测算）。
- 分段计划会按实测注水量自动推进，到位时震动并播报，不用一直盯秒表。
- 「完成并记品鉴」会把实测注水量、实测粉重和实际粉水比带进品鉴记录。
- 还没有秤时点「看一下示例曲线」，可以按真实节拍先看一遍图表效果。

### 电子秤

- 支持 TIMEMORE Basic3 / Dot / ESPpro。协议按 `A5 5A` 帧实现（服务 `FFF0`、通知 `FFF1`、写入 `FFF2`，CRC16/MODBUS 大端，重量包 `0x01`），广播用 `0xFFFF` 制造商数据识别型号。
- 桌面 Chrome、Edge 和安卓浏览器点「连接电子秤」直接走 Web Bluetooth，数据不出本机。
- iOS 的 Safari 和 Chrome 都没有 Web Bluetooth，新增「用手机当桥」：在能连蓝牙的设备上打开 `bridge.html` 连秤，两台设备登录同一账号即可，不用记房间码。
- 中继挂在账号服务上（`/api/scale/relay`）：握手先验登录 Cookie，未登录返回 401；房间按账号隔离，只有推流方能广播，只能透传重量与流速。房间只在内存里，不落盘、不记录读数，没人后自动回收。
- 需要安全上下文：`https://` 或 `localhost` 才显示连接能力，`http://` 局域网访问会禁用按钮并给出原因。
- 新增 `scale-bridge-server.mjs`，既能挂在账号服务里，也能用 `CAFE_SCALE_PORT` 单独跑做本机调试。

### 粉水比与分段

- 冲煮表单新增粉水比（1:14–1:18）与预计时长。默认 15 g 粉、225 g 水、1:15，三个数互相印证。
- 「按粉水比重算水量」改粉量或比数后一键算出总水量，各段累计注水等比缩放，末段严格对齐。
- 「按预计时长排段」把各段结束秒数重排到目标时长，水量不变；标题下实时显示参考排段。

### 文档与测试

- README 增加「电子秤」章节，含 Nginx 与 Caddy 的 WebSocket 透传配置片段，说明 `wss://` 与证书要求。
- 新增协议层、粉水比计算、中继转发与鉴权的测试；`node --test` 全绿。

### 升级提示

- 静态站点需要一起上传 `bridge.html` 和 `core/scale*.mjs`，并让 `/api/scale/` 的 `Upgrade` 头透传到账号服务，否则 iOS 路线会 502。
- 冲煮页的缓存版本号已递增（`preview.css?v=14`、`preview.mjs?v=14`、`workspace.mjs?v=12`），刷新一次即可拿到新界面。
